# Harvest modules

`lib/harvest/*` is the permission fence and the reading rules behind the crawl
CLIs, so its laws live with the commands that spend them, in
[scripts/AGENTS.md](../../scripts/AGENTS.md). Read that before changing a source
policy, a robots answer or a price reader.

Everything else under `lib/` is [lib/AGENTS.md](../AGENTS.md), and the repo-wide
laws are the root [AGENTS.md](../../AGENTS.md).
