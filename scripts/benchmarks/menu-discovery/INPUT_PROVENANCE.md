# Input provenance

The manifest selects venue facts from the repository's OpenStreetMap snapshot.
OpenStreetMap data is available under the [Open Database Licence](https://opendatacommons.org/licenses/odbl/1-0/).
Attribution: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

The snapshot identifies its source as OpenStreetMap Overpass and its licence as ODbL.
Its recorded fetch time is 6 October 2026, 00:13:28 UTC.
The manifest records the original snapshot hash and each selected OSM object ID.

The London app snapshot supplies a second identity and location check.
The preparation script requires a matching pub name and coordinates within 150 metres.
The app snapshot does not itself prove that the website is current or official.
The review rubric requires official-site address evidence before a menu receives a verified label.

The input uses existing website tags. It does not fetch a directory, search engine, map API, or commercial lead source.
Website ownership, menu content, and access conditions can change after the source snapshot.
Blocked sites and stale website tags stay visible as findings.
