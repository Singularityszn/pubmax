The skills

Pick a layer, run a skill.

 Nine AI skills — one for each of the seven layers of product design, plus a diagnostic and a framework primer. Tool-agnostic; install once, run in your AI tool of choice.

Install the skills

 One command installs all nine skills. They become available in whichever AI tool you use.

 Install in Claude Code, Cursor, Codex & more

`npx skills add jamiemill/layers-skills`CopyCopied
 Install once with the skills package, then run any `/layers-*` skill in your AI tool.
