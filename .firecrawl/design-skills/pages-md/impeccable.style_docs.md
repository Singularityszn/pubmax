Start with /impeccable

Install, add context, then run one command.

01Install`npx impeccable install`Run from the project root, then reload your agent.

02Set context`/impeccable init`Create PRODUCT.md and DESIGN.md.

03Try it`/impeccable polish the pricing page`Point it at a real page.

Full session path

Plan, build, review, refine.

[Plan/impeccable shapeThink before you build. Produce a design brief through discovery, not guesswork.](/docs/shape)

[Build/impeccable craftDesign it, then build it, all in one flow.](/docs/craft)

[Review/impeccable critiqueA design review with scoring, persona tests, and automated detection.](/docs/critique)

[Refine/impeccable polishThe meticulous final pass between good and great.](/docs/polish)

Already shipped? Use [/impeccable polish](/docs/polish) on the page that needs work, or [/impeccable audit](/docs/audit) for checks.

Useful command pairs

Use these when one pass is not enough.

[bolder](/docs/bolder)↔[quieter](/docs/quieter)

Two halves of voice. Loud or restrained, never neutral.

[audit](/docs/audit)→[harden](/docs/harden)

Find the technical issues. Then fix them.

[critique](/docs/critique)→[polish](/docs/polish)

Review the work. Then refine it.

[shape](/docs/shape)→[craft](/docs/craft)

Plan the feature. Then build the plan.

Full command reference

Create 3

[craftDesign it, then build it, all in one flow.](/docs/craft)

[impeccableGet a next-step recommendation, or describe design work in plain English.](/docs/impeccable)

[shapeThink before you build. Produce a design brief through discovery, not guesswork.](/docs/shape)

Evaluate 2

[auditFive-dimension technical quality check with P0 to P3 severity.](/docs/audit)

[critiqueA design review with scoring, persona tests, and automated detection.](/docs/critique)

Refine 8

[animatePurposeful motion that conveys state, not decoration.](/docs/animate)

[bolderPush safe designs toward impact without sliding into chaos.](/docs/bolder)

[colorizeAdd strategic color to monochrome interfaces without going garish.](/docs/colorize)

[delightSmall moments of personality that turn functional into memorable.](/docs/delight)

[layoutFix layout, spacing, and visual rhythm.](/docs/layout)

[overdrivePush an interface past conventional limits. Shaders, physics, 60fps, cinematic transitions.](/docs/overdrive)

[quieterTone down designs that are shouting without losing their intent.](/docs/quieter)

[typesetFix typography that feels generic, inconsistent, or accidental.](/docs/typeset)

Simplify 3

[adaptMake designs work across screens, devices, and contexts without amputating features.](/docs/adapt)

[clarifyRewrite confusing UX copy so interfaces explain themselves.](/docs/clarify)

[distillRuthless subtraction. Strip designs to their essence.](/docs/distill)

Harden 4

[hardenMake interfaces production-ready. Edge cases, i18n, error states, overflow.](/docs/harden)

[onboardDesign first-run experiences, empty states, and paths to value.](/docs/onboard)

[optimizeDiagnose and fix UI performance from LCP to bundle size.](/docs/optimize)

[polishThe meticulous final pass between good and great.](/docs/polish)

System 3

[documentGenerate a spec-compliant DESIGN.md that captures your visual system so every AI agent stays on-brand.](/docs/document)

[extractPull reusable components, tokens, and patterns into the design system.](/docs/extract)

[liveIterate on UI in the browser. Pick an element, drop a comment, get three variants. Accept one and it writes to source.](/docs/live)
