# Context.dev London pub observations

Production-build browser captures for the [Context.dev harvest](../../../data/harvest/contextdev-whats-on/README.md).
The desktop captures use 1440 by 1000 pixels. The phone captures use 500 by 844 pixels.

| File | What it shows |
| --- | --- |
| `venue-hours-after-desktop.png`, `venue-hours-after-mobile.png` | The Coach and Horses venue sheet with the published opening hours and their observation date. |
| `tonight-before-desktop.png`, `tonight-before-mobile.png` | The Tonight view before the harvest. |
| `tonight-after-desktop.png`, `tonight-after-mobile.png` | The Tonight view after the harvest. |

The Tonight captures show the current empty state after midnight on 8 October.
They do not prove that the future event cards rendered. The reader tests cover those records and the expired-event filter.
The captures were taken before the final publish removed the Greene King fixture rows.
The final counts are in `data/harvest/contextdev-whats-on/proof/data-before-after.json`.
