## Gallery behaviour and bytes

The actual browser selected and decoded five AVIF photos per device in cold and warm cases.
The source URLs matched the baseline photos. Requested widths stayed within the 640-pixel ceiling.
Each source had one proxy request, without a duplicate WebP request during successful AVIF decode.
A deliberately corrupt AVIF response retried the same photo as WebP and preserved its source caption.

| Device | Requested width | Five WebP bodies | Five AVIF bodies | Saving |
| --- | ---: | ---: | ---: | ---: |
| Mobile | 640 px | 255,106 bytes | 178,383 bytes | 30.07% |
| Desktop | 384 px | 102,666 bytes | 72,126 bytes | 29.75% |

These are encoded photo body sizes. Warm cache transfer was zero for those photos.
The mobile result exceeds the separate 80 KB five-photo target, so that issue remains open.
The change applies only to decorative gallery photos. Priority photos retain their existing path.
AVIF encoding costs more CPU than WebP. The five-photo offline check measured 112-156 ms
for 640-pixel AVIF and 20-27 ms for WebP.
The inspected comparison retained readable frontage and signs, with mild AVIF smoothing.

## Keyboard finding

The desktop browser case initially omitted MapLibre's native attribution summary from its selector.
Actual IAB inspection at 1280 by 720 pixels confirmed this order:
Zoom out, Toggle attribution, Search pubs. The test selector was corrected without removing boundary assertions.
The corrected desktop case passed on the compiled candidate in 17.7 seconds.

Actual IAB inspection at 900 by 900 pixels found a separate product defect.
Tab from Zoom out wrapped to the venue drawer's Back control and skipped the visible attribution summary.
A separate reviewed focus-trap repair includes the first native summary unless its Tab index is minus one.
Its new hook regression failed before the repair. The owner reported 44 focused tests passing after the repair.
The repair is included in the combined source after the measured candidate.
It still needs runtime proof on a build containing the repair.
That proof must check Zoom out to attribution to drawer at 900 pixels and the reverse boundary.
