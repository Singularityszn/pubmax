Removing daily pages from the CDN changes the standing nonce/cache decision. Scheduled revalidation introduces operational work. This branch changes none of those policies. Add Today to the sitemap only after that decision.
2. Keep new neighbourhood or station documents under #1522 and PlanAstra #1576/#1581. Query intent is an area or transport arrival, with existing borough and area/drink canonicals checked first. A proposal needs resolved venue IDs, dated source rows, measured station proximity, a publication floor, one canonical, internal links and route/metadata tests. Each new document would need real ordered stops, dated prices where available and unique sourced information. Walking figures require actual routing or an explicit estimate label.

5. Confirm Three Colts identity and inspect plan, save, crawl, memory and price references before any reconciliation. Destructive work remains outside this task.
6. Provide authorised Search Console access or an export for measurement. Use the prior matrix's export checklist with the current deployment ID. Compare the same country, device, search type and two equal 28-day windows. Keep branded, price, neighbourhood, station, event and crawl queries separate. URL Inspection must record the inspection time, Google canonical, verdict and last crawl separately. Average position is an aggregate, not a fixed ranking.

For Soho and Shoreditch, improve links inside the existing borough and eligible area/drink families first. For station arrivals, propose a station guide only after the captain chooses a namespace and publication floor. Check existing borough and area/drink canonicals before naming a new route. Link it from the matching borough or map arrival only after route, canonical, floor, sitemap and source-date tests agree. The small Waterloo sample is a reason to withhold publication until coverage improves, not to lower a floor. Keep this proposal with #1522 and #1576/#1581.
