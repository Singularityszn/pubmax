## Additional runtime findings

The no-JavaScript browser caught a Crawls defect that text extraction missed.
Its route content arrived inside a hidden streaming boundary.
The fix passes pack and shared-story parameters from the server and removes that blank boundary.
Client navigation still receives new server parameters.

The existing document-privacy browser test rejected public auth-cleanup code because it names token keys.
The corrected test rejects serialized token values and retains its handle checks.
No production token was present in the captured document.

Out now accepts a public server answer scoped to its city, day and render time.
A fresh answer avoids an immediate duplicate provider request.
Retries, another city, a five-minute-old answer or a London service-day rollover require a new read.
Render time never becomes source freshness.
