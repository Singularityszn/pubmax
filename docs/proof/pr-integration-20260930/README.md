Event clocks no longer read "until closing time", "start time" or "TILL LATE" as zones; any other stated zone, including "ET", "PT", "MSK" and "Moscow time", is refused unless it is London, UK, local, GMT, UTC, BST or a numeric offset, and each refusal is counted as `ungrounded`. An alcohol-free night with a per-person ceiling still fails closed with 422 while the same ceiling on pints returns 200: pint prices are never used as alcohol-free price evidence. A wine ledger row harvested as "Merlot 175ml" now shares its key with a re-read "Merlot" 175ml row, so the bundle builder and ledger rebuild keep only the newer row.
