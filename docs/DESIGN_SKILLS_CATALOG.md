# PubMax design skills

UI and design-taste skills for this repo live under `.agents/skills/`. Commits and directory names are in [`.agents/skills/SOURCES.md`](../.agents/skills/SOURCES.md).

| Pack | Use it for |
| --- | --- |
| [emilkowalski/skills](https://github.com/emilkowalski/skills) | Motion, polish, and design engineering. Start with `emil-design-eng`. |
| [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | Visual taste. `taste-skill` is `design-taste-frontend`. `redesign-skill` is an audit-first pass over existing UI. |
| [jakubkrehel/skills](https://github.com/jakubkrehel/skills) | Interface craft: layout, type, colour, accessibility. `better-ui` and `better-interface` are the broad passes. |
| [gnurio/refactoring-ui-plugin](https://github.com/gnurio/refactoring-ui-plugin) | Atomic hierarchy, type, colour, spacing, buttons, clutter, empty states, shadows, contrast, and grouping. `meta-refactor-ui` runs the set. |
| [shadcn-labs/skills](https://github.com/shadcn-labs/skills) | shadcn registry launch, icon sets, and Tailwind to StyleX. |

MapLibre and Capacitor skills in the same directory are for the map and the native shell, not for visual taste.
