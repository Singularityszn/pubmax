# Original Pal models

These seven models derive from the existing Circuit Pal portraits. Their original PNG and WebP files remain unchanged. The front textures preserve the original RGB artwork. The geometry outside the original view is inferred.

The 21 October 2026 user instruction authorizes these models in the app. Each owned large portrait loads only its selected species. The phone voice face uses the same model and remains decorative. Compact avatars and unclaimed portraits retain their images.

The original portrait remains visible during loading, reduced motion, and model or graphics failure. The renderer uses the existing voice signal. Arrow keys turn the large portrait, and Home faces forward.

Each GLB contains its texture and has no external resource URL. The standard Three texture loader uses the existing image policy. The security policy remains unchanged. A texture failure cannot replace the portrait with an untextured model.

`provenance.json` binds each model to its original portrait. `TripoSR-LICENSE.txt` preserves the reconstruction source licence. Live deployment and physical-device acceptance require separate verification.
